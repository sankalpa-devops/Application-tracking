## 1️⃣ Job Profile Creation & Deletion (Core ATS Module)

### 🔹 Job Profile Structure

Each job profile should include:

* **Job Title / Role**
* **Department**
* **Job Type** (Full-time / Part-time / Contract / Intern)
* **Experience Range**
* **Required Skillsets** (Primary & Secondary)
* **Location / Remote**
* **Hiring Manager**
* **Openings Count**
* **Status** (Open / Closed / On Hold)
* **Created Date & Created By**

### 🔹 Functional Capabilities

* Create / Edit / Archive / Delete job profiles
* Clone existing job profiles
* Skill tagging (used later for resume matching)
* Job role versioning (track changes over time)

### 🔹 AI Enhancements (Recommended)

* **Auto skill extraction** from job description
* **Job description quality score**
* Skill gap warnings (if JD is unrealistic)
* Market demand indicator for skills

## 3️⃣ Blacklisted Candidate Identification

### 🔹 Blacklist Data Points

* Email
* Phone number
* Aadhaar / PAN (hashed)
* Previous employee ID
* Face match (optional future scope)
* Reason for blacklisting
* Blacklist expiry (optional)

### 🔹 Detection Flow

* On resume upload → auto scan
* On manual candidate creation → real-time check
* On walk-in entry → instant alert

### 🔹 AI Enhancements

* Duplicate identity detection
* Alias name detection
* Email/phone pattern analysis
* Risk scoring system

### 🔹 HR Dashboard Behavior

* Highlight blacklisted candidates in **RED**
* Show reason + history
* Restrict progression unless overridden
